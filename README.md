# Happy Birthday Aurelian

A cinematic, responsive birthday experience built as a dependency-free static site for GitHub Pages.

## What changed

- Reworked the visual system into a cleaner editorial/glass hybrid with stronger hierarchy and responsive layouts.
- Removed broken references to missing favicon/audio assets.
- Added an accessible intro flow, skip path, focus states, reduced-motion support, semantic sections, and an accessible celebration dialog.
- Replaced the heavy continuous canvas animation stack with lightweight CSS motion and viewport-triggered reveals.
- Added an opt-in Web Audio soundscape so audio never starts unexpectedly.
- Added canonical/OG/Twitter metadata, a favicon, `robots.txt`, and `sitemap.xml`.
- Kept the original portrait and memory collage assets while lazy-loading the non-hero image.

## Deployment

The site is configured for GitHub Pages from the `main` branch root.
